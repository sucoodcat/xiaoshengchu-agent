# 小升初路径导航Agent v2.0

昆明市小升初全流程AI信息整合与路径推演系统。为家长提供从"志愿填报后"到"初中入学"的全流程行动规划。

**v2.0更新**：DeepSeek V4引擎 · 摇号前双场景模式 · 动态时间线 · 学校对比 · 知识库扩至9模块

---

## 快速启动（网页版）

```bash
# 1. 进入项目目录
cd ~/Desktop/小升初路径导航Agent

# 2. 安装依赖（仅首次）
pip3 install -r requirements.txt

# 3. 配置 API Key
#    编辑 .env 文件，填入你的 DeepSeek API Key
#    获取地址：https://platform.deepseek.com

# 4. 启动
$HOME/Library/Python/3.9/bin/streamlit run app.py
```

浏览器打开 **http://localhost:8501** 即可使用。API Key已预设于服务器端，家长无需自行输入。

## v2.0 核心功能

| 功能 | 说明 |
| :--- | :--- |
| 🎯 双场景模式 | 摇号前自动生成"摇中"和"未摇中"两套行动方案 |
| ⏳ 动态时间线 | 基于今日日期，自动计算倒计时，区分紧急/进行中/已完成 |
| 📊 学校对比 | 支持2-3所学校并排对比（性质/学费/分班/升学/校风） |
| 🏫 1+2推荐 | 基于用户小学和志愿，推荐1个首选+2个备选 |
| 📅 精确日历 | 行动日期精确到日，每项标注信息来源 |
| 📋 信息收集 | 侧边栏卡片式收集，选填越多规划越精准 |
