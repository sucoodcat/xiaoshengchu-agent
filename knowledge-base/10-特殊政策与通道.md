# 特殊政策与通道

> ⚠️ 本文件基于历年公开政策整理，仅供参考。特殊通道政策每年可能调整，请以当年官方公告为准。
> 信息覆盖：云南省教育厅、昆明市教体局、各区教体局历年文件

## 一、家迁（家庭搬迁）对升学的影响

> ⚠️ 本节基于昆明市教体局及各区教体局官方文件整理，已交叉验证。政策核心来源：西山区2025年初中招生范围、官渡区教体局回复、昆明市义招网公告。

### 1.1 公办初中分配基本原则（必须了解的前提）

昆明市公办初中分配的核心依据是**小学学籍划片**，而非小区或房产：

> "一校单点或一校多点、九年一贯以校划片，结合户口（或人户分离的实际居住地），免试、免费、就近或相对就近分配入学"

⚠️ **官方明确：不存在"某小区对口某初中"的固定对应关系。** [来源：官渡区教体局公开回复]

分配优先级：**人户一致（户口+房产在同一区）> 人户分离（以实际居住地为主）**

### 1.2 家迁对升学的真实影响（三种路径）

#### 路径A：已迁户至目标区（人户一致）—— 需主动申请

**条件**：已将孩子户籍迁至新房产所在地，且房产为监护人全产权。

**操作流程**：
1. 在就读小学参加毕业考试
2. **通过就读小学向目标区教体局提交书面申请**，申请回户籍/居住地就读初中
3. 由就读小学和目标区教体局审查证明材料（户口本+房产证+学籍卡）
4. 符合条件的，由目标区教体局**统筹安排**就读初中

⚠️ **统筹≠自由选择**：统筹是由区招办根据片区内初中空余学位情况统一调配，结果不一定是最邻近的初中。不能假设"搬到XX小区就能上XX初中"。

⚠️ **关键时间**：4月20日-24日为"个别生"建档窗口（仅限非主城区学籍学生）。主城区学籍学生通过就读小学统一办理，但书面申请仍需尽早提交。

#### 路径B：仅搬家、未迁户（人户分离）—— 走随迁子女通道

**条件**：已搬到新房产居住，但户口未迁移。

**操作流程**：
1. 需凭在居住地派出所办理的**《云南省居住证》或《暂住登记证明》**（须在当年2月28日前办理且有效）
2. 按随迁子女政策申请公费学位
3. 由区教体局根据学位情况统筹安排

⚠️ 随迁子女通道的学位保障优先级低于人户一致。

#### 路径C：不申请跨区，留在原学籍地 —— 默认路径

**条件**：不提交跨区申请。

**结果**：按就读小学的对口初中正常分配（走"以校划片"）。这是最稳妥的路径。

### 1.3 家迁对民办摇号的影响

- 民办摇号（义招网统一报名）**不受户籍限制**，面向全市招生
- 摇中后确认录取即可，无需考虑户籍问题
- 未摇中则回到公办分配路径（按上述A/B/C三种情况）

### 1.4 家迁的定向择优资格风险

- **初中三年内跨区转学**将丧失定向择优资格（初升高）
- 如果入学后因搬迁需要转学，定向资格将中断
- **建议**：尽量在小升初阶段完成搬迁和户籍迁移，避免初中阶段转学

### 1.5 关键时间节点

| 时间 | 事项 | 对家迁家庭的意义 |
| :--- | :--- | :--- |
| 当年2月28日前 | 居住证/暂住登记证明办理截止 | 仅搬家不迁户者必须在此前办好 |
| **4月20日-24日** | 非主城区学籍毕业生建档 | 跨区就读的非主城区学籍学生必须到目标区现场办理 |

| 初中入学后 | 原则上不再办理跨区转学 | 毕业年级不准转学 |

### 1.7 Agent应对家迁用户的强制规则

**在给家迁用户出具任何建议前，必须逐条确认以下事实，不得凭猜测作答：**

1. ☐ 用户是否已完成户籍迁移？（已迁/未迁/办理中）
2. ☐ 用户搬迁目标区是哪里？
3. ☐ 用户搬迁时间节点是何时？（已搬/1个月内/3个月内/半年内）
4. ☐ 根据以上信息，判断属于路径A/B/C中的哪一种？

**回答家迁问题时必须包含**：
- 明确告知用户属于哪种路径（A/B/C）
- 给出该路径的具体操作步骤和所需材料
- 标注关键时间窗口
- 给出目标区教体局咨询电话
- **绝不凭空断言"您会被统筹至XX学校"**，只能说"目标区可能统筹的学校包括XX等，具体以区教体局分配结果为准"
- ⚠️ 声明：统筹分配结果以区教体局官方通知为准

## 二、双胞胎/多胞胎政策

### 2.1 昆明市现行政策

- **摇号捆绑**：双胞胎家庭可选择"捆绑摇号"（一个号摇中，两个同时录取）或"分开摇号"（各自独立摇）
- **捆绑利弊**：
  - 利：两个孩子同校，方便接送，家庭教育一致性
  - 弊：捆绑后中签概率与单人相同（不是双倍），可能两个都不中
- **分开摇利弊**：
  - 利：至少一个摇中的概率增大
  - 弊：可能两个在不同学校，增加接送和沟通成本

### 2.2 公办统筹中的双胞胎

- 统筹分配时会尽量安排同校，但不绝对保证
- 建议主动向区教体局申请同校分配

### 2.3 Agent应对双胞胎的话术要点

- 明确提示捆绑/分开两种选择的利弊
- 结合家庭情况（接送便利性、孩子独立性）给出建议
- 提示统筹阶段主动申请同校

## 三、体育特长生通道

### 3.1 政策背景

- 2020年起国家收紧特长生招生，但昆明部分学校仍保留体育特色项目
- 传统体育特色校可通过体育测试降分或优先录取

### 3.2 昆明体育特色初中

| 学校 | 体育特色项目 | 招生方式 |
| :--- | :--- | :--- |
| 昆八中 | 篮球（传统强校）、田径 | 校内选拔 + 体育测试 |
| 昆十中 | 游泳、羽毛球 | 校内选拔 |
| 昆三中 | 足球、田径 | 体育特长生测试 |
| 官一中 | 田径、篮球 | 校内选拔 |

### 3.3 体育特长生的关键时间节点

- 通常在各校分班考试同期或稍早进行体育测试
- 需提前准备：获奖证书、比赛成绩、教练推荐信
- 建议在报名阶段就主动联系目标学校体育组

### 3.4 Agent应对体育特长的话术要点

- 识别用户特长是否匹配目标学校的体育特色项目
- 给出主动联系学校体育组的建议和联系方式
- 提示体育测试与分班考的时间可能冲突，需提前规划

## 四、艺术特长生通道

### 4.1 昆明艺术特色初中

| 学校 | 艺术特色项目 |
| :--- | :--- |
| 昆十中 | 管乐团（省级知名）、舞蹈 |
| 白塔中学 | 艺术特色（昆十中体系） |
| 云大附中 | 合唱团、美术 |

### 4.2 艺术特长生的关键点

- 艺术特长生通道比体育更窄，大多数学校不做正式降分录取
- 更多作为分班后进入高水平社团的参考
- 但在面试/综合评价环节可能有隐性加分

## 五、三好学生/优秀学生干部等荣誉

### 5.1 荣誉对小升初的影响

- **公办初中**：荣誉在分班时有一定参考价值，尤其是"市级三好学生"
- **民办初中**：摇号阶段无影响（纯随机），但摇中后分班时荣誉可作为参考
- **初升高阶段**：荣誉在综合素质评价中有明确加分

### 5.2 荣誉等级与影响力

| 荣誉等级 | 影响力 | 说明 |
| :--- | :--- | :--- |
| 省级三好学生/优秀少先队员 | ⭐⭐⭐ | 含金量最高，部分学校重点关注 |
| 市级三好学生/优秀学生干部 | ⭐⭐ | 分班参考价值较高 |
| 区级三好学生 | ⭐ | 有一定参考价值 |
| 校级三好学生 | ½⭐ | 基本参考价值 |

### 5.3 Agent应对荣誉的话术要点

- 在分班考备考建议中提及荣誉的参考价值
- 建议家长在新生报到时携带荣誉证书复印件
- 不过度夸大荣誉的作用（对摇号无影响）

## 六、学科竞赛获奖

### 6.1 竞赛对小升初的影响

- **数学竞赛**（华杯、希望杯、省/市数学竞赛）：含金量最高，部分初中在分班时重点参考
- **信息学竞赛**（NOIP普及组等）：云大附中等科技特色校重点关注
- **英语竞赛**（外研社杯等）：有一定参考价值
- **作文竞赛**：参考价值相对较低

### 6.2 竞赛获奖等级与影响力

| 竞赛类型 | 等级 | 影响力 |
| :--- | :--- | :--- |
| 数学竞赛 | 省级一等奖及以上 | ⭐⭐⭐⭐ 分班考参考价值很高 |
| 数学竞赛 | 省级二等奖/市级一等奖 | ⭐⭐⭐ |
| 信息学竞赛 | 省级奖项 | ⭐⭐⭐ 科技特色校重点关注 |
| 英语竞赛 | 省级奖项 | ⭐⭐ |
| 科技创新大赛 | 省级奖项 | ⭐⭐ |

### 6.3 Agent应对竞赛的话术要点

- 匹配目标学校的优势学科和竞赛特色
- 数学竞赛获奖者在分班考中有明显优势，但仍需认真备考
- 如果目标校有竞赛传统（如云大附中），应重点提及

## 七、其他特殊情况

### 7.1 华侨/港澳台/外籍子女
- 有专门的入学通道，需联系市教体局侨务办公室
- 部分学校（云大附中等）有专门的国际班/港澳台班

### 7.2 残疾/特殊教育需求
- 随班就读政策保障入学权利
- 可申请特殊教育支持

### 7.3 军人/公安英烈子女
- 有优待政策，优先安排入学
- 需提前向区教体局提交相关证明材料

## 八、Agent综合调用指引

在处理用户咨询时，Agent必须：

1. **家迁**：结合搬迁时间和目标区域，给出迁户建议+定向资格风险提示+目标区学校推荐
2. **双胞胎**：明确对比捆绑/分开的利弊，结合家庭情况给出建议
3. **体育/艺术特长**：匹配目标校特色项目，给出联系方式和时间节点
4. **三好学生/荣誉**：在分班考部分提及，建议携带证书
5. **竞赛获奖**：匹配目标校竞赛传统，在分班考备考中体现优势
6. **所有特殊因素必须在报告中明确体现**，不能只收集不使用
