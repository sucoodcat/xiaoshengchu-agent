# 特殊政策与通道

> ⚠️ 本文件基于历年公开政策整理，仅供参考。特殊通道政策每年可能调整，请以当年官方公告为准。
> 信息覆盖：云南省教育厅、昆明市教体局、各区教体局历年文件

---

## 一、家迁（家庭搬迁）对升学的影响

> ⚠️ 本节为家迁政策的核心定义，经多次核实修正。Agent必须以此为准，不得偏离。

### 1.1 家迁的核心定义（最重要）

**完成家迁（户口迁至新房产所在地，人户一致）的学生，小升初路径如下：**

1. **可以参加全市统一摇号**：与所有昆明市学生一样，在义招网（kmyzw.cn）正常报名并填报民办/民转公初中志愿，参与电脑随机摇号。
2. **摇中** → 去摇中的学校就读（与家迁无关，摇号面向全市）。
3. **未摇中** → 按照**家迁后的属地辖区**（新户口所在地）的**对口统筹**安排初中就读，而非按原小学学籍地对口。

**简单来说：家迁后 = 摇号资格不变 + 未摇中则按新户籍地统筹。**

### 1.2 家迁 vs 未家迁的关键区别

| 情形 | 摇号资格 | 未摇中后的去向 |
| :--- | :--- | :--- |
| 未家迁（原学籍地） | ✅ 可参加全市摇号 | 按原小学学籍对口公办初中 |
| **已完成家迁（人户一致）** | ✅ 可参加全市摇号 | **按新户籍地辖区对口统筹** |
| 仅搬家、未迁户（人户分离） | ✅ 可参加全市摇号 | 按原小学学籍地或居住证地址统筹 |

### 1.3 操作要点

- 家迁（户口迁移）应在义招网报名前完成，确保报名信息与户籍一致
- 在义招网报名时填写新的户籍地址
- 如摇号未中，系统根据报名时填写的户籍地址进行公办统筹分配
- 无需额外提交"跨区申请"——新户籍地址在报名时直接录入系统

### 1.4 定向择优资格提醒

- 初中三年内如因再次搬迁转学，可能丧失初升高定向择优资格
- 建议家迁后尽量稳定，避免初中阶段再次转学

### 1.5 Agent应答家迁问题的规则

**回答家迁问题时必须按以下逻辑：**
1. 确认用户是否已完成户口迁移（人户一致）
2. 告知：可以正常参加摇号
3. 告知：如摇中→去摇中学校；如未摇中→按新户籍地辖区统筹
4. 给出新户籍地所在区的教体局咨询电话
5. ⚠️ 不承诺具体统筹到哪所学校（统筹由区教体局统一安排）

## 二、双胞胎/多胞胎政策

### 2.1 昆明市现行政策

- **摇号捆绑**：双胞胎家庭可选择"捆绑摇号"（一个号摇中，两个同时录取）或"分开摇号"（各自独立摇）
- **捆绑利弊**：
  - 利：两个孩子同校，方便接送，家庭教育一致性
  - 弊：捆绑后中签概率与单人相同（不是双倍），可能两个都不中
- **分开摇利弊**：
  - 利：至少一个摇中的概率增大
  - 弊：可能两个在不同学校，增加接送和沟通成本

### 2.2 公办统筹中的双胞胎

- 统筹分配时会尽量安排同校，但不绝对保证
- 建议主动向区教体局申请同校分配

### 2.3 Agent应对双胞胎的话术要点

- 明确提示捆绑/分开两种选择的利弊
- 结合家庭情况（接送便利性、孩子独立性）给出建议
- 提示统筹阶段主动申请同校

## 三、体育特长生通道

### 3.1 政策背景

- 2020年起国家收紧特长生招生，但昆明部分学校仍保留体育特色项目
- 传统体育特色校可通过体育测试降分或优先录取

### 3.2 昆明体育特色初中

| 学校 | 体育特色项目 | 招生方式 |
| :--- | :--- | :--- |
| 昆八中 | 篮球（传统强校）、田径 | 校内选拔 + 体育测试 |
| 昆十中 | 游泳、羽毛球 | 校内选拔 |
| 昆三中 | 足球、田径 | 体育特长生测试 |
| 官一中 | 田径、篮球 | 校内选拔 |

### 3.3 体育特长生的关键时间节点

- 通常在各校分班考试同期或稍早进行体育测试
- 需提前准备：获奖证书、比赛成绩、教练推荐信
- 建议在报名阶段就主动联系目标学校体育组

### 3.4 Agent应对体育特长的话术要点

- 识别用户特长是否匹配目标学校的体育特色项目
- 给出主动联系学校体育组的建议和联系方式
- 提示体育测试与分班考的时间可能冲突，需提前规划

## 四、艺术特长生通道

### 4.1 昆明艺术特色初中

| 学校 | 艺术特色项目 |
| :--- | :--- |
| 昆十中 | 管乐团（省级知名）、舞蹈 |
| 白塔中学 | 艺术特色（昆十中体系） |
| 云大附中 | 合唱团、美术 |

### 4.2 艺术特长生的关键点

- 艺术特长生通道比体育更窄，大多数学校不做正式降分录取
- 更多作为分班后进入高水平社团的参考
- 但在面试/综合评价环节可能有隐性加分

## 五、三好学生/优秀学生干部等荣誉

### 5.1 荣誉对小升初的影响

- **公办初中**：荣誉在分班时有一定参考价值，尤其是"市级三好学生"
- **民办初中**：摇号阶段无影响（纯随机），但摇中后分班时荣誉可作为参考
- **初升高阶段**：荣誉在综合素质评价中有明确加分

### 5.2 荣誉等级与影响力

| 荣誉等级 | 影响力 | 说明 |
| :--- | :--- | :--- |
| 省级三好学生/优秀少先队员 | ⭐⭐⭐ | 含金量最高，部分学校重点关注 |
| 市级三好学生/优秀学生干部 | ⭐⭐ | 分班参考价值较高 |
| 区级三好学生 | ⭐ | 有一定参考价值 |
| 校级三好学生 | ½⭐ | 基本参考价值 |

### 5.3 Agent应对荣誉的话术要点

- 在分班考备考建议中提及荣誉的参考价值
- 建议家长在新生报到时携带荣誉证书复印件
- 不过度夸大荣誉的作用（对摇号无影响）

## 六、学科竞赛获奖

### 6.1 竞赛对小升初的影响

- **数学竞赛**（华杯、希望杯、省/市数学竞赛）：含金量最高，部分初中在分班时重点参考
- **信息学竞赛**（NOIP普及组等）：云大附中等科技特色校重点关注
- **英语竞赛**（外研社杯等）：有一定参考价值
- **作文竞赛**：参考价值相对较低

### 6.2 竞赛获奖等级与影响力

| 竞赛类型 | 等级 | 影响力 |
| :--- | :--- | :--- |
| 数学竞赛 | 省级一等奖及以上 | ⭐⭐⭐⭐ 分班考参考价值很高 |
| 数学竞赛 | 省级二等奖/市级一等奖 | ⭐⭐⭐ |
| 信息学竞赛 | 省级奖项 | ⭐⭐⭐ 科技特色校重点关注 |
| 英语竞赛 | 省级奖项 | ⭐⭐ |
| 科技创新大赛 | 省级奖项 | ⭐⭐ |

### 6.3 Agent应对竞赛的话术要点

- 匹配目标学校的优势学科和竞赛特色
- 数学竞赛获奖者在分班考中有明显优势，但仍需认真备考
- 如果目标校有竞赛传统（如云大附中），应重点提及

## 七、其他特殊情况

### 7.1 华侨/港澳台/外籍子女
- 有专门的入学通道，需联系市教体局侨务办公室
- 部分学校（云大附中等）有专门的国际班/港澳台班

### 7.2 残疾/特殊教育需求
- 随班就读政策保障入学权利
- 可申请特殊教育支持

### 7.3 军人/公安英烈子女
- 有优待政策，优先安排入学
- 需提前向区教体局提交相关证明材料

## 八、Agent综合调用指引

在处理用户咨询时，Agent必须：

1. **家迁**：结合搬迁时间和目标区域，给出迁户建议+定向资格风险提示+目标区学校推荐
2. **双胞胎**：明确对比捆绑/分开的利弊，结合家庭情况给出建议
3. **体育/艺术特长**：匹配目标校特色项目，给出联系方式和时间节点
4. **三好学生/荣誉**：在分班考部分提及，建议携带证书
5. **竞赛获奖**：匹配目标校竞赛传统，在分班考备考中体现优势
6. **所有特殊因素必须在报告中明确体现**，不能只收集不使用
