# 政策与流程库

> ⚠️ 本文件基于公开政策文件整理。政策每年可能微调，请以昆明市教体局及义招网官方发布为准。

---

## 一、小升初核心政策

### 1. 核心原则
- **公民同招**：公办初中和民办初中同步招生，同步录取
- **免试就近入学**：公办初中按户籍/学籍对口直升，不设入学考试
- **电脑随机摇号**：热门民办初中报名人数超过招生计划时，实行电脑随机摇号录取
- **每位学生仅限报一所民办初中**作为第一志愿

### 2. 招生方式

| 学校类型 | 招生方式 | 说明 |
| :--- | :--- | :--- |
| 公办初中 | 对口直升 | 按小学对口关系或户籍地分配 |
| 民办初中（报名≤招生） | 直接录取 | 所有报名学生全部录取 |
| 民办初中（报名>招生） | 电脑摇号 | 通过义招网统一摇号，随机录取 |
| 公参民学校 | 按当年政策 | 政策变动较大，需关注最新通知 |

### 3. 关键角色：义招网
- 全称：昆明市义务教育阶段招生入学系统
- 官网：昆明市教育体育局指定平台
- 功能：网上报名、志愿填报、摇号结果查询、录取通知

## 二、2026年小升初关键时间节点（历年规律推演）

| 时间 | 事项 | 说明 |
| :--- | :--- | :--- |
| **5月下旬-6月初** | 义招网开放报名 | 填报基本信息及民办初中志愿 |
| **6月中旬** | 报名截止 | 信息锁定，不可更改 |
| **6月下旬** | **民办初中电脑摇号** | 义招网统一摇号，结果当天公布 |
| **摇号公布后24-48小时** | **补录窗口期** | 部分民办校释放未确认名额，启动补录 |
| **7月上旬** | 公办初中录取结果公布 | 公布对口直升及统筹分配结果 |
| **7月中旬** | 录取确认期 | 家长到录取学校确认报到 |
| **7月下旬-8月中旬** | **各校分班考试** | 各初中校自行组织，时间不统一 |
| **8月下旬** | 新生报到、注册 | 携带相关材料到校报到 |
| **9月1日** | 正式开学 | |

## 三、补录机制详解

### 1. 补录产生的原因
- 摇中确认后，部分学生选择放弃（已回国/去其他城市/选国际学校等）
- 学校释放空余名额，进行二次补录
- **补录窗口极短**，通常在摇号结果公布后24-48小时内完成

### 2. 如何获取补录信息
- 关注目标民办校官网、微信公众号
- 加入各校小升初家长群（微信群/QQ群）
- 主动致电目标学校招生办咨询
- 留意义招网公告

### 3. 历年有补录记录的民办校（不完全统计）
- 云大附中一二一校区（少量名额）
- 师大实验中学（少量名额）
- 长城中学
- 白塔中学
- 云子中学
- 滇池中学
- ⚠️ 每年情况不同，以上仅为历年记录，不代表当年必有补录

## 四、统筹分配机制

### 1. 统筹规则
- 未摇中民办的学生，由区教体局统筹分配至公办初中
- **江湖规律**：优先回对口公办，但对口学校学位饱和时可能被调剂
- 统筹结果不可选择，由主管部门统一安排

### 2. 各区域统筹趋势

| 区域 | 统筹方向估算 | 学位紧张程度 |
| :--- | :--- | :--- |
| 五华区 | 优先回对口公办，满额后调剂至区内其他公办 | 中等偏紧张 |
| 盘龙区 | 优先回对口公办 | 中等 |
| 官渡区 | 优先回对口公办 | 相对宽松 |
| 西山区 | 优先回对口公办，部分调剂 | 中等 |
| 呈贡区 | 优先回对口公办 | 相对宽松 |

### 3. 被统筹后的应对策略
- **立即了解统筹校的分班机制**：是否有重点班/优质班
- **准备分班考试**：公办校的分班考试同样重要，优质班资源集中
- **接受现实，积极规划**：在公办校争取定向择优名额是另一条有效路径

## 五、初升高定向择优名额政策

### 1. 什么是定向择优？
- 一级一等完中将招生计划的一部分名额"定向"分配给各初中学校
- 初中校内竞争，分数从高到低录取，直到用完名额
- **定向录取线通常低于统招录取线10-20分**

### 2. 定向资格条件
- 在目标初中连续就读满三年（完整学籍）
- 中间转学或跨区就读可能丧失定向资格
- ⚠️ 这是小升初择校时需重点考虑的因素

### 3. 定向名额分配原则
- 按初中学校毕业生人数比例分配
- 向薄弱初中有所倾斜
- 具体名额每年由教体局统一公布

## 六、其他重要提示

### 学区房 vs 学籍
- 公办初中对口主要看**小学学籍**，而非房产
- 跨区择校需谨慎评估学籍转移带来的定向资格问题

### 转学风险
- 初中阶段转学可能导致丧失定向择优资格
- 小升初是最后一次"零成本"择校窗口
